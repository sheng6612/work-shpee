# 🧰 Work Shpee

> 工作回報與排班管理工具
> 讓每天的工作回報、排班與資料整理變得更簡單。

<p align="center">

### 🚀 立即使用

**👉 [開啟 Work Shpee](https://shpee-liart.vercel.app/)**

不需要安裝、不需要註冊帳號，使用瀏覽器即可直接使用。

</p>

---

## 📌 這是什麼？

**Work Shpee** 是一個為日常工作設計的輕量化工作輔助工具。

主要將平常需要重複輸入的工作回報與排班資訊集中在同一個介面，讓使用者可以快速完成：

**填寫 → 確認 → 複製 → 回報**

不需要每次重新整理格式，也不需要手動輸入目前時間。

---

## ✨ 目前功能

### 📋 工作回報

提供常用的工作回報格式：

- 📦 SCS 上架完成回報
- 📦 NDD 上架完成回報
- 📦 NDD 打包完成回報
- 📦 SCS HD 打包完成回報

可以填寫：

- 到貨／打包箱數
- 完成時間
- 無法處理數量
- 無法處理原因

---

### ⏰ 自動取得目前時間

完成工作後，可以直接點擊：

> **現在**

系統會自動取得目前時間，不需要手動輸入。

---

### 📋 一鍵複製

每個工作項目都可以單獨複製。

也可以使用：

> **複製全部**

一次產生完整的工作回報。

例如：

```text
8/12
民主橫
NDD上架完成回報
🔸到貨箱數：14
🔸上架完成時間:21:35
🔸無法上架顆數：0
```

複製後可以直接貼到工作群組。

---

### 💾 自動儲存

輸入中的資料會自動儲存在瀏覽器的 `localStorage`。

因此重新整理頁面後，當天已經輸入的資料仍然可以保留。

> ⚠️ 資料目前儲存在「目前使用的瀏覽器」中，不是雲端資料庫。

# 🔐 資料會不會被上傳？

目前版本**不需要登入，也沒有後端資料庫**。

資料主要儲存在：

```text
你的瀏覽器
    │
    ▼
localStorage
    │
    └── 工作回報資料
```

因此：

- 不需要註冊
- 不需要登入
- 不需要建立帳號
- 不需要資料庫
- 不同裝置之間不會自動同步

⚠️ 如果清除瀏覽器的網站資料，原本儲存的回報資料可能會一起被刪除。

# 💻 本機開發

如果想在自己的電腦執行：

```bash
git clone https://github.com/sheng6612/work-shpee.git

cd work-shpee

bun install
```

啟動開發環境：

```bash
bun dev
```

然後開啟：

```text
http://localhost:3000
```
